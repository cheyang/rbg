RESULT: both carriers refuse the operation. The difference:
  - template fail  : release untouched, no failed revision, but lookup is
                     blind client-side, so fail-closed false-fails helm-diff.
  - hook Job       : leaves a 'failed' revision (recoverable without --force),
                     but sees real cluster state, can reuse the controller's
                     own Go constants, and is SKIPPED by helm-diff so it
                     cannot false-fail.
