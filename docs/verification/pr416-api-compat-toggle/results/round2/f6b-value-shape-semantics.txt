=== flag-validity check: is each rendered flag value a legal Go bool literal? ===
Go's flag package accepts 1 0 t f T F true false TRUE FALSE True False and rejects
everything else, including the empty string. The chart now ALWAYS renders the flag, so
an unparseable value crashloops the manager instead of being silently ignored.
  --set controller.deprecatedWorkloadTypes.enabled=false     -> --enable-deprecated-workload-types=false       legal
  --set controller.deprecatedWorkloadTypes.enabled=true      -> --enable-deprecated-workload-types=true        legal
  --set controller.deprecatedWorkloadTypes.enabled=0         -> --enable-deprecated-workload-types=0           legal
  --set controller.deprecatedWorkloadTypes.enabled=          -> --enable-deprecated-workload-types=            ILLEGAL -> flag.Parse error -> manager CrashLoopBackOff

Reading of the table:
  * Shapes 1-5 and 7: the new block is guarded (`| default dict` + `hasKey`) and the parent
    `controller:` block coalesces with the chart defaults, so a missing, empty or partially
    written block falls back to the chart default (enabled, 8/8 RBAC entries, flag=true).
    The round-1 F6 behaviour -- a partial block silently stripping RBAC -- is FIXED.
  * Shape 8c (`enabled:` left blank in a values file) was the round-1 silent-strip case. Helm
    treats an explicit null in a user values file as "delete this key", so it coalesces back
    to the chart default: 8/8 and flag=true. Also fixed.
  * Shape 6 (`controller: null`) still hard-fails -- but it hard-fails on the BASE commit too,
    at manager.yaml:9 `.Values.controller.replicaCount`. This PR only changes which template
    reports the nil pointer first. PRE-EXISTING, not a finding against this PR.
  * Shape 8b (`--set ...enabled=""`) renders `--enable-deprecated-workload-types=` with an
    empty value. RBAC is stripped consistently, but the flag string itself is rejected by Go's
    flag parser, so the manager would CrashLoopBackOff rather than start restricted. Other
    flags in this chart pipe through `| default`, so they degrade instead. Minor: it requires
    the operator to assign an empty string to a boolean.
